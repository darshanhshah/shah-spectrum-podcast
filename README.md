# Shah Spectrum podcast feed

Public feed, cover art and approved episodes only. Scripts, drafts and unapproved audio live elsewhere.

- Feed: https://darshanhshah.github.io/shah-spectrum-podcast/feed.xml
- Cover: cover.jpg (3000 x 3000)
- Add an approved episode: put the mp3 in `episodes/`, then run `scripts/add_episode.py`.
- Draft mode: nothing is added to `feed.xml` until the audio is approved.

Narrated by an AI-generated voice.
